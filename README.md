There Add-ons in the repository:

 - [Anki Progression](https://github.com/Eltaurus-Lt/Lt-Anki-Addons/tree/main/Progression) - Add-on for displaying customizable daily progress bars

Add-on templates (can be used as a base for building other Anki add-ons):

 - [Anki Styling Template](https://github.com/Eltaurus-Lt/Lt-Anki-Addons/tree/main/Injecting%20css%20and%20js%20%5Btemplate%5D) - Injects custom css and js into Anki windows to modify styling and front-end functionality
 - [Editor Button and Context menu](https://github.com/Eltaurus-Lt/Lt-Anki-Addons/tree/main/Editor%20button%20and%20context%20menu%20%5Btemplate%5D) - Adds a button to the Anki editor toolbar and an item to the browser context menu

Obsolete add-ons:
 - [Lstyle](https://github.com/Eltaurus-Lt/Lt-Anki-Addons/tree/main/Lstyle) (merged into [Memrise Card Templates](https://github.com/Eltaurus-Lt/Anki-Card-Templates)) - Modifies the main deck window, allowing adding thumbnails for the decks and manually adjusting their order
 - [Ps](https://github.com/Eltaurus-Lt/Lt-Anki-Addons/tree/main/Ps) (merged into [Anki-Contextualize](https://github.com/Eltaurus-Lt/Anki-Contextualize)) - Allows opening images from a card in an image editor (Photoshop by default) with a single click
